This repository contains scripts and data relating to the manuscript: \
**Phylogenies as graphs: structured neural networks improve host origin predictions from paramyxovirus sequences**

All paths are relative to the root directory.\
Numeric prefixes indicate process order to carry out all data processing and modelling described in the manuscript.

Most directories contain a single R script which carries out all necessary processes for this step in the analysis. Where the step requires more than one script, individual README files are provided.
